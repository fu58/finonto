检修中心设备与备件台账（片段）

表 t_equipment（设备台账）
equipment_id 设备编号 string(32) 主键，形如 EQ-2号机组-汽轮机高压缸
equipment_name 设备名称 string(128)
functional_location 功能位置 string(64) 外键，关联 t_functional_location，表示设备安装与归属位置
criticality 设备关键度 code 枚举：A/B/C，A 类停机将造成主流程中断
health_state 健康状态 code 枚举：正常/注意/异常/失效
run_hours 累计运行小时 decimal(12,1)
last_overhaul_date 上次大修日期 date 大修周期不得超过 6 年
manufacturer 制造商 string(128)
model 型号 string(64)
data_classification 数据分级 code 枚举：S1/S2/S3

表 t_equipment_part（设备部件）
part_id 部件编号 string(32) 主键
equipment_id 设备编号 string(32) 外键，部件包含于设备
part_name 部件名称 string(128) 如 叶轮、轴承、机械密封、叶片
material 材质 string(64)
design_life_hours 设计寿命小时 integer
failure_mode_code 故障模式编码 string(32) 遵循 ISO 14224 失效分类

表 t_inspection（点检记录）
inspection_id 点检编号 string(32) 主键
inspection_type 点检类型 code 枚举：日常点检/定期点检/精密点检/巡回检查
equipment_id 设备编号 string(32) 外键
inspector_id 点检人 string(32) 外键，关联 t_technician
measured_value 实测值 decimal(12,4)
unit 单位 string(16) 振动 mm/s、温度 ℃
threshold 报警阈值 decimal(12,4) 实测值超过阈值即登记缺陷
found_defect 是否发现缺陷 boolean
photo_evidence 影像留痕 string(256)

表 t_defect（缺陷台账）
defect_id 缺陷编号 string(32) 主键
equipment_id 设备编号 string(32) 外键
defect_phenomenon 缺陷现象 string(256) 如 轴承温度偏高、密封渗漏
defect_level 缺陷等级 code 枚举：一般/重大/紧急
escalated_failure 是否升级为故障 boolean 升级为故障的缺陷必须在 4 小时内开出维护工单
detected_by 发现方式 code 枚举：点检/巡检/状态监测/操作发现
close_date 消缺日期 date

表 t_failure（故障记录）
failure_id 故障编号 string(32) 主键
equipment_id 设备编号 string(32) 外键
failure_mode 故障模式 string(64) 如 轴承磨损、叶轮裂纹、绝缘劣化
failure_cause 故障原因 string(256)
stop_hours 停机时长小时 decimal(8,2)
work_order_id 关联工单 string(32) 外键，故障触发维护工单
occurred_at 发生时间 datetime

表 t_work_order（维护工单）
work_order_id 工单号 string(32) 主键
strategy 维保策略 code 枚举：预防性维护/预测性维护/事后维修
equipment_id 设备编号 string(32) 外键
team_id 班组 string(32) 外键，工单派工给维修班组
plan_start 计划开始时间 datetime
actual_finish 实际完成时间 datetime
labor_hours 工时时 decimal(8,2)
permit_id 作业许可 string(32) 外键，动火等危险作业必须挂接作业许可
status 工单状态 code 枚举：待派工/已派工/执行中/待验收/已关闭

表 t_task（检修作业）
task_id 作业编号 string(32) 主键
work_order_id 工单号 string(32) 外键
procedure_id 检修规程 string(32) 外键，作业依据规程执行
tooling_id 工具仪表 string(32) 外键，作业需使用已校准的工具仪表
calibrated 仪表是否在校准有效期内 boolean 校准周期不得超过 12 个月

表 t_spare_part（备件主数据）
spare_code 备件编码 string(32) 主键
spare_name 备件名称 string(128)
replaces_part 可更换部件 string(32) 外键，关联 t_equipment_part
unit_price 单价 decimal(12,2) 单位元
safety_stock 安全库存 integer 不得低于近 12 个月平均消耗量的 1.5 倍
lead_time_days 采购周期天数 integer 关键备件不得超过 30 天
storage_location 库位 string(64) 外键，关联 t_inventory

表 t_inventory（备件库存）
inventory_id 库存记录 string(32) 主键
spare_code 备件编码 string(32) 外键，备件存储于备件库存
warehouse 仓库 string(64)
on_hand 在库数量 integer
locked 锁定数量 integer 已被工单预留
available 可用数量 integer 等于在库数量减去锁定数量

表 t_technician（维修人员）
technician_id 人员编号 string(32) 主键
name 姓名 string(64)
team_id 所属班组 string(32) 外键，班组由人员组成
skill_level 技能等级 code 枚举：初级/中级/高级/技师
certificates 持证工种 string(256) 如 低压电工证、压力容器作业证，属 S3 数据
data_classification 数据分级 code 枚举：S1/S2/S3

表 t_reliability_metric（可靠性指标月报）
metric_id 指标编号 string(32) 主键
equipment_id 设备编号 string(32) 外键，指标统计自故障记录并评价设备
period 统计周期 string(8) 形如 2026-09
mtbf 平均故障间隔小时 decimal(10,2)
mttr 平均修复时间小时 decimal(10,2) A 类设备不得超过 8
availability 可用率 decimal(6,4) A 类设备不得低于 0.98
inspection_detect_rate 点检发现率 decimal(6,4) 目标值不低于 0.6
cost 维修成本 decimal(14,2) 单位元
