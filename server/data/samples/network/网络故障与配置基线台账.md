网络运维中心故障与配置基线台账（片段）

表 t_host（主机清单）
host_id 主机标识 string(32) 主键，如 core-pay-prd-app01
os 操作系统 string(64) 如 Kylin V10、Ubuntu 22.04
business_system 所属业务系统 string(64)
online_date 上线日期 date
host_state 主机状态 code 枚举：在线/维护/下线/隔离
data_classification 敏感分级 code 枚举：N1/N2/N3

表 t_device（网络设备）
device_name 设备名称 string(64) 主键，如 BJ1-CORE-SW01
device_type 设备类型 code 枚举：交换机/路由器/防火墙/负载均衡器/无线控制器
vendor_model 厂商型号 string(64)
software_version 软件版本 string(32)
serial_number 序列号 string(64) 属 N2 内部数据
room_location 机房位置 string(64) 如 北京亦庄 A 机房 3 列 12 柜

表 t_interface（网络接口）
interface_id 接口标识 string(48) 主键，如 BJ1-CORE-SW01 TenGigE1/0/24
interface_name 接口名称 string(32)
port_speed 标称速率 integer 单位 Mbps，取 1000/10000/40000
admin_state 管理状态 code 枚举：启用/关闭
oper_state 运行状态 code 枚举：up/down/dormant
mtu 最大传输单元 integer 生产业务域统一 9000，跨运营商链路 1500

表 t_link（网络链路）
link_id 链路编号 string(48) 主键，格式 LK-BJ1-SH1-CT-01
link_type 链路类型 code 枚举：光纤专线/双绞线/专线电路/无线链路
contract_bandwidth 契约带宽 integer 单位 Mbps
carrier 运营商 string(32) 枚举：中国电信/中国联通/中国移动
redundancy 冗余方式 code 枚举：双链路负载/主备/单链路

表 t_subnet（子网）
subnet_id 子网标识 string(32) 主键
prefix 子网前缀 string(43) 如 10.20.30.0/24，遵循 RFC 1918
gateway 网关地址 string(45)
usable_hosts 可用地址数 integer 生产业务域不得少于 64
used_hosts 已分配地址数 integer 超过可用地址数 80% 需扩容
vlan_id VLAN 编号 integer 取值 1~4094，生产业务域段 200~299

表 t_ip_address（地址池）
ip_value 地址值 string(45) 主键
ip_version 协议版本 code 枚举：IPv4/IPv6
assign_mode 分配方式 code 枚举：静态/DHCP
lease_days 租期 integer DHCP 租期不得超过 8 天
is_public 是否公网地址 boolean 为真时必须登记责任人
owner 责任人 string(32)

表 t_mac_address（物理地址登记）
mac_value 地址值 string(17) 主键，形如 3c:52:82:1a:04:7f
oui_prefix 厂商前缀 string(8) 前 3 字节 OUI

表 t_route（路由表基线）
route_id 路由标识 string(32) 主键
destination_prefix 目的前缀 string(43)
next_hop 下一跳 string(45)
egress_interface 出接口 string(48)
admin_distance 管理距离 integer 静态路由不得超过 100
route_source 路由来源 code 枚举：直连/静态/OSPF/BGP

表 t_acl_policy（访问控制策略）
policy_id 策略编号 string(32) 主键
action 动作 code 枚举：允许/拒绝
source_range 源地址范围 string(128) 必须为子网或地址组，禁止 any
dest_range 目的地址范围 string(128)
order_no 生效顺序 integer 数值越小越先匹配
expire_date 有效期 date 不得超过 180 天
cross_zone 是否跨安全域 boolean 跨域必须附申报单号

表 t_vpn_tunnel（VPN 隧道）
tunnel_id 隧道编号 string(32) 主键
tunnel_type 隧道类型 code 枚举：IPsec/SSL/TLS-PSK
cipher 加密算法 string(32) 如 AES-256-GCM
peer_address 对端地址 string(45)
established_at 建立时间 datetime 建立超过 30 秒判定异常

表 t_service（网络服务）
service_name 服务名称 string(64) 主键，如 dns-corp、ntp-primary、api.prd.corp.example.com
service_type 服务类型 code 枚举：DNS/NTP/HTTP/HTTPS/数据库访问/消息
availability 可用性状态 code 枚举：正常/降级/中断

表 t_port（服务端口）
port_no 端口号 integer 联合主键
transport 传输协议 code 枚举：TCP/UDP
app_protocol 应用协议 string(32) 如 HTTPS、SSH、MySQL
exposure 暴露范围 code 枚举：仅本机/管理域/办公域/生产域/公网
process 所属进程 string(64)

表 t_dns_record（DNS 记录）
record_value 记录值 string(128)
record_type 记录类型 code 枚举：A/AAAA/CNAME/MX/TXT/SRV
ttl TTL integer A 记录不得超过 600 秒，CNAME 不得超过 3600 秒
priority 优先级 integer 仅 MX 与 SRV 需要填写

表 t_certificate（TLS 证书）
cert_serial 证书序列号 string(64) 主键
issuer 颁发机构 string(128)
sig_algorithm 签名算法 string(32) 不得低于 SHA-256
not_before 生效日期 date
not_after 到期日期 date 有效期不得超过 397 天，到期前 30 天更换
bound_domain 绑定域名 string(128)

表 t_incident（网络故障事件）
incident_id 事件编号 string(32) 主键，如 INC-2026-0918-03
occurred_at 发生时间 datetime
recovered_at 恢复时间 datetime
impact_minutes 影响时长 integer 一级事件超过 15 分钟须出根因分析
category 故障类别 code 枚举：连通性/性能劣化/配置错误/设备硬件/安全策略
severity 严重程度 code 枚举：一级/二级/三级
affected_target 影响对象 string(64) 关联链路编号或服务名称
root_cause 根因 string(256)

表 t_metric（网络性能指标）
metric_name 指标名称 string(64) 如 链路时延、接口抖动、丢包率、带宽利用率、TCP 重传率
metric_value 指标值 decimal(12,4)
unit 单位 string(16) ms / % / Mbps
sample_period 采样周期 integer 单位秒，不得超过 60
threshold 阈值 decimal(12,4) 同机房时延 5、跨机房 30、抖动 3、丢包率 0.1、带宽利用率 70
interface_id 关联接口 string(48) 外键

表 t_log（网络日志）
log_time 日志时间 datetime
level 日志级别 code 枚举：紧急/错误/警告/注意/信息/调试
source_addr 来源地址 string(45)
message 日志内容 string(512)
retention_days 保存期限 integer 生产设备不少于 180 天，安全域相关不少于 365 天

表 t_topology（网络拓扑版本）
topology_name 拓扑名称 string(64) 如 全行骨干网拓扑
version_no 版本号 string(16) 每次割接后必须递增
updated_date 更新日期 date 不得早于最近一次变更时间
scope 覆盖范围 string(128) 如 北京上海两地三中心
