零售信贷核心系统数据字典（片段）

表 t_customer（客户主表）
customer_id 客户号 string(32) 主键，行内唯一
customer_name 客户名称 string(128) 个人客户填姓名，企业客户填工商注册名称
id_type 证件类型 code 枚举：身份证/统一社会信用代码/护照/港澳台居民居住证
id_no 证件号码 string(32) 身份证 18 位，统一社会信用代码 18 位
risk_level 客户风险等级 code 枚举：低风险/中风险/高风险/禁止类
kyc_status 尽调状态 code 枚举：待尽调/尽调中/已尽调/需强化尽调
created_at 建档时间 datetime

表 t_credit_account（授信账户表）
account_id 授信账户号 string(32) 主键
customer_id 客户号 string(32) 外键，关联 t_customer
credit_limit 授信额度 decimal(18,2) 单位元，不得超过客户核定的最高授信额度
available_balance 可用额度 decimal(18,2) 等于授信额度减去在贷余额
credit_status 授信状态 code 枚举：生效/冻结/注销/到期
review_date 复核日期 date 至少每半年复核一次
quota_type 额度类型 code 枚举：循环额度/非循环额度/专项额度

表 t_loan_contract（借款合同表）
contract_id 合同号 string(32) 主键
account_id 授信账户号 string(32) 外键，关联 t_credit_account
customer_id 客户号 string(32) 外键，关联 t_customer
principal 放款本金 decimal(18,2) 单位元
interest_rate 年利率 decimal(9,6) 以小数表示，不得低于定价下限
term_months 期限月数 integer 消费贷不超过 12 期，经营贷不超过 36 期
repay_method 还款方式 code 枚举：等额本息/等额本金/先息后本/一次性还本付息
five_category 五级分类 code 枚举：正常/关注/次级/可疑/损失
overdue_days 逾期天数 integer 逾期 90 天以上自动下调为次级
written_off 是否核销 boolean

表 t_collateral（押品表）
collateral_id 押品编号 string(32) 主键
contract_id 合同号 string(32) 外键，关联 t_loan_contract
collateral_type 押品类型 code 枚举：房产/土地/车辆/存单/应收账款/股权/机器设备
appraisal_value 评估价值 decimal(18,2) 单位元，需由准入评估机构出具报告
appraisal_date 评估日期 date 至少每年重估一次
pledgor 出质人 string(128)
mortgage_rate 抵押率 decimal(5,2) 房产不超过 70%，车辆不超过 50%，存单不超过 90%

表 t_guarantee（担保表）
guarantee_id 担保编号 string(32) 主键
contract_id 合同号 string(32) 外键，关联 t_loan_contract
guarantor_name 担保人名称 string(128)
guarantee_type 担保方式 code 枚举：保证/抵押/质押/信用
guarantee_amount 担保金额 decimal(18,2)
guarantee_scope 担保范围 string(256) 含本金、利息、违约金与实现债权的费用

表 t_repayment_plan（还款计划表）
plan_id 计划编号 string(32) 主键
contract_id 合同号 string(32) 外键，关联 t_loan_contract
period_no 期次 integer
due_date 应还日期 date
due_principal 应还本金 decimal(18,2)
due_interest 应还利息 decimal(18,2)
paid_amount 实还金额 decimal(18,2)
overdue_flag 逾期标志 boolean

表 t_transaction_flow（交易流水表）
flow_id 流水号 string(32) 主键
account_id 账户号 string(32) 外键
trans_date 交易日期 date
trans_amount 交易金额 decimal(18,2)
counterparty 交易对手 string(128)
is_large_amount 是否大额 boolean 达到大额交易报送标准时置为真
suspicious_flag 可疑标志 boolean 命中可疑交易规则时置为真
